# Ticketly Backend Engine 🎬
This is a professional backend system built with **FastAPI** and **SQLAlchemy**.

### Features:
- **API Endpoints:** For booking and viewing tickets.
- **Database:** SQLite integration for permanent storage.
- **Data Analysis:** Exporting booking data to CSV using Pandas.

### How to run:
1. Open the `.ipynb` file in Google Colab.
2. Run all cells to start the server.
3. Use the testing cell to book tickets.
